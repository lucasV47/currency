# Currency

This Python script utilizes the requests library to interact with the Free Currency API for real-time currency conversion. The script allows users to convert a specified base currency into a selection of other currencies, including USD, JPY, EUR, and BRL.

## Key Features:
- API Integration: Connects to the Free Currency API using an API key for authentication.
- Dynamic Currency Conversion: Users can input any base currency to receive the latest conversion rates for the specified currencies.
- Error Handling: The script includes basic error handling to manage invalid currency inputs and API response issues.
- User -Friendly Interface: A simple command-line interface prompts users for input and displays conversion results in a readable format.

## Usage Instructions:

Ensure you have the requests library installed. You can install it using pip:
'pip install requests'

Run the script and follow the prompts to convert currencies. Type 'Q' to exit the program.
